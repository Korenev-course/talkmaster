# TalkMaster — Телеграм‑бот для практики разговорного английского
_Мгновенные диалоги на реальные темы и мягкие правки формулировок — прямо в Telegram._

> Кейс: рабочий MVP‑бот на **Python** с **OpenAI Chat Completions**. Диалоги ведутся в чате Telegram; выбор сценариев — через **инлайн‑кнопки**. Исправления и короткие пояснения задаются через системные инструкции модели (см. `system_instruct.txt`).

---

## Боль / контекст
Большинство «курсов по расписанию» ломаются о быт: нет регулярности, неудобно согласовывать время, стыдно ошибаться вслух. Нужен формат «всегда под рукой», где можно писать как в обычном чате, получать более естественные формулировки и короткие пояснения — без избыточной грамматики и без долгого онбординга.

## Цель
Дать пользователю **простой способ ежедневной разговорной практики** в одном окне Telegram: начать за минуту, говорить на своих темах и сразу видеть, *как сказать лучше*.

## Решение (высокоуровнево)
- Телеграм‑бот на **Python** + **Telegram Bot API** (инлайн‑кнопки для сценариев).
- **OpenAI Chat Completions**; поведение задаётся через `system_instruct.txt` (роль, тон, формат правок).
- **Мягкие правки и пояснения** встроены в ответы модели: без «красной ручки», только по делу.
- Никаких установок — всё работает в чате Telegram.

---

## Путь пользователя (step‑by‑step)
1. **Старт:** нажимаете «Запустить» в Telegram‑чате бота.  
2. **Выбор сценария:** через инлайн‑кнопки (например: свободный диалог, интервью‑формат, путешествия).  
3. **Диалог:** пишете как обычно — бот отвечает естественно и держит тему.  
4. **Мягкие правки:** где уместно, бот предлагает более естественные формулировки и даёт короткое пояснение (за счёт системных инструкций модели).  
5. **Вернуться позже:** просто откройте чат снова и продолжите разговор (контекст в пределах лимита модели).

> **Важно:** в текущем MVP нет «уровней A2/B1/B2», недельных отчётов и напоминаний — эти функции в бэклоге (см. ниже).

## Метрики (гипотезы для пилота)
*Этот блок — **ориентиры для проверки гипотез**; обновите цифры по фактическим замерам после тестового периода.*
- **Time‑to‑practice ≈ 1 минута**: запуск без онбордингов/регистраций.  
- **3–5 диалогов/неделю** у занятых пользователей за счёт формата «как переписка».  
- **Снижение повторяющихся ошибок** в пределах 2–4 недель (по ручной выборке сообщений).

## Чем полезно бизнесу/школам
- Повышает удержание: «лёгкая» ежедневная практика между занятиями без нагрузки на преподавателя.  
- Снимает рутину с кураторов: базовые исправления и короткие пояснения делает бот.  
- Масштабируется сценариями: добавляйте/меняйте кнопки без переписывания ядра.

## Стек и архитектура (коротко)
- **Python 3.x** + Telegram Bot API (инлайн‑кнопки / InlineKeyboardButton).  
- **OpenAI Chat Completions**; поведение и формат ответов — через `system_instruct.txt`.  
- **config.py / переменные окружения** для токенов/ключей.  
- Логи в stdout; без отдельной БД в текущем MVP.

## Приватность (MVP)
В текущем MVP бот **не использует долговременное хранилище**: сообщения не пишутся в отдельную БД. Обработка выполняется в рамках Telegram‑чата и вызовов модели. Для продакшена запланированы политика конфиденциальности и опции согласия на сбор обезличенной статистики.

## Бэклог → следующая итерация
- Уровни сложности (A2/B1/B2+) и тональность ответа.  
- Еженедельный дайджест: «повторяющиеся ошибки» и «фразы недели».  
- Напоминания о практике («вернуться завтра»).  
- Экспорт заметок/фраз в карточки (Anki/Quizlet).
